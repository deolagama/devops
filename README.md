# DevOps Lab Exercises

This repository contains my implementations and documentation for the **DevOps Lab exercises** completed as part of my coursework.

The exercises cover containerization, Docker networking and security, Kubernetes deployments and scaling, multi-node cluster management, application monitoring with Grafana, and CI/CD automation using Jenkins.

Each exercise is organized into a separate directory with its implementation details, commands, configurations, verification steps, and screenshots wherever applicable.

## Repository Purpose

The purpose of this repository is to document and maintain a record of the practical work completed throughout the DevOps Lab.

For each exercise, the documentation includes:

- Objective and requirements
- Tools and technologies used
- Commands and configurations implemented
- Step-by-step implementation details
- Verification and testing procedures
- Screenshots and evidence of execution
- Final outcome and observations

This repository serves as both a record of completed coursework and a practical reference for DevOps concepts and tools.
