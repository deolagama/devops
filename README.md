# DevOps Lab

This repository contains my implementations and documentation for the **DevOps Lab exercises** completed as part of my coursework.

The exercises cover various DevOps concepts, including containerization, orchestration, CI/CD, cloud computing, and related technologies. Each exercise is documented separately with the commands, configurations, implementation steps, verification results, and screenshots wherever applicable.

## Repository Purpose

The purpose of this repository is to maintain a record of the practical work completed throughout the DevOps Lab.

For each exercise, I document:

- The objective of the exercise
- Tools and technologies used
- Commands and configurations implemented
- Important implementation steps
- Verification of the expected results
- Screenshots and evidence of successful execution
- Final outcome

This repository serves as both a **record of completed coursework** and a reference for the concepts and tools used during the lab.

## Exercises

All exercises are organized inside the [`Exercises`](https://github.com/lakshyaaa76/DEVOPS/tree/main/Exercises) directory.

Each exercise has its own folder containing the relevant documentation and implementation artifacts.

```text
Exercises/
├── 1-Kubernetes-Getting-Started/
├── Exercise-2/
├── Exercise-3/
└── ...
```

Each exercise folder contains the documentation and evidence relevant to that particular exercise.

## How to Use This Repository

Start with the `Exercises` directory to navigate through the lab exercises.

For a particular exercise:

1. Open its folder inside `Exercises`.
2. Read the `README.md` file for the objective and implementation details.
3. Review the commands and configurations used.
4. Check the verification steps and results.
5. Refer to the screenshots and other artifacts included in the folder.

## Documentation Approach

The documentation focuses on **my actual implementation and results** rather than simply reproducing the original lab instructions.

For exercises involving practical execution, screenshots and other relevant artifacts are included wherever applicable to demonstrate successful implementation and verification.
